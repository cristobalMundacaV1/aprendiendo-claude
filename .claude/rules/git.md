# Regla: Git

Cuando trabajes en este repositorio:

- Revisa `git status` antes de modificar archivos.
- No descartes cambios del usuario.
- No uses `git reset --hard`, `git clean -fd` ni force push sin autorización explícita.
- Antes de un commit, muestra un resumen del diff.
- Los mensajes de commit deben explicar el propósito del cambio.
