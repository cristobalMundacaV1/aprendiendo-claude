# Regla: seguridad

- Nunca escribas secretos reales dentro del repositorio.
- Usa valores ficticios como `TU_TOKEN_AQUI`.
- No abras ni imprimas archivos `.env` salvo que el usuario lo solicite y entienda el riesgo.
- Si una acción puede destruir datos, detener servicios o publicar información, avisa antes de ejecutarla.
