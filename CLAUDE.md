# CLAUDE.md — Aprendiendo Claude

## Propósito del repositorio

Este repositorio enseña a una persona principiante a usar Claude Code correctamente desde cero.

## Cómo trabajar aquí

- Prioriza explicaciones simples, concretas y en español.
- No asumas conocimientos avanzados de Git, terminal, MCP o agentes.
- Cuando modifiques documentación, conserva ejemplos ejecutables y fáciles de copiar.
- No agregues secretos, tokens, claves, correos privados ni credenciales reales.
- Antes de editar varios archivos, explica brevemente qué vas a cambiar.
- No borres material pedagógico útil sin reemplazarlo por una alternativa mejor.
- Mantén los ejemplos pequeños: este repo enseña conceptos, no intenta ser un framework.

## Validación

Antes de cerrar un cambio:

1. Revisa enlaces relativos.
2. Verifica que los ejemplos JSON sean válidos cuando corresponda.
3. Comprueba que ningún archivo contenga secretos reales.
4. Resume qué cambió y qué debería aprender el lector.

## Git

- No hagas force push.
- No reescribas historial sin solicitud explícita.
- Prefiere commits pequeños con mensajes descriptivos.
