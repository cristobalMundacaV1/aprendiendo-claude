# 14 — Glosario

**Agent / agente**  
Modelo que puede usar herramientas y ejecutar pasos para alcanzar un objetivo.

**Agent loop**  
Ciclo observar → decidir → actuar → validar → repetir.

**CLAUDE.md**  
Archivo de instrucciones persistentes que Claude Code puede cargar al trabajar en un repositorio.

**Contexto**  
Información disponible para el modelo durante una tarea: conversación, archivos, resultados de herramientas, instrucciones, etc.

**Definition of Done**  
Condiciones objetivas que deben cumplirse para considerar una tarea terminada.

**Gate**  
Comprobación que debe pasar antes de avanzar, por ejemplo tests, lint o build.

**Hook**  
Automatización que se ejecuta ante un evento concreto de Claude Code.

**Human-in-the-loop**  
Diseño donde un humano interviene en decisiones o acciones importantes, mientras el resto se automatiza.

**Idempotencia**  
Propiedad de una operación que puede repetirse sin duplicar el efecto final.

**MCP**  
Model Context Protocol. Estándar para conectar agentes con herramientas y fuentes externas.

**Project Instructions**  
Instrucciones compartidas por los chats de un Claude Project.

**Project Knowledge**  
Documentos y archivos de referencia disponibles dentro de un Claude Project.

**Rule**  
Instrucción especializada almacenada normalmente en `.claude/rules/`.

**Skill**  
Paquete de instrucciones reutilizables que enseña a Claude a realizar un procedimiento.

**Subagent**  
Agente especializado con contexto separado que realiza una parte concreta del trabajo.

**Supervisor**  
Agente que coordina otros agentes, integra resultados y decide escalaciones.

**Worker**  
Agente encargado de una subtarea acotada.

**Worktree**  
Función de Git que permite tener varias copias de trabajo del mismo repositorio, cada una en una rama distinta.
