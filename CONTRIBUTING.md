# Contribuir

Este repositorio está pensado como material educativo.

Si agregas contenido:

1. Prioriza claridad antes que cantidad.
2. Comprueba la documentación oficial de Claude Code.
3. Evita instrucciones dependientes de una versión concreta salvo que lo indiques.
4. No agregues secretos o credenciales reales.
5. Mantén ejemplos pequeños y reproducibles.
6. Actualiza navegación si agregas una guía importante.
