# Playground

Mini proyecto para practicar con Claude Code sin tocar un sistema importante.

Prueba:

~~~text
Explora este playground y explícame qué hace sin modificar nada.
~~~

Luego:

~~~text
Agrega soporte para multiplicación.
Primero crea un test que falle, después implementa el cambio y ejecuta las pruebas.
~~~

O:

~~~text
Revisa app.js buscando casos límite. No edites nada; entrega hallazgos primero.
~~~
